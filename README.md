# FoodSaver AI

AI-powered platform for reducing food waste through food analysis,
expiry prediction, food donation, NGO connection, and pickup management.

## Project Modules

- User Authentication
- Smart Pantry
- AI Food Analysis
- Expiry Prediction
- Food Donation
- NGO Finder
- Pickup Management
- Notifications
- Analytics Dashboard
- Admin Dashboard

## Technology Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- AI: Python
- Database: To be finalized
